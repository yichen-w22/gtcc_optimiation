# 探索性数据分析总结

整理日期：2026-10-01。项目：GARD燃气—蒸汽联合循环运行分析与优化。

本文汇总原 `results/` 和 `探索分析_20260930/` 的报告、关键统计与后续研究启发。按用户要求，整理并核对本文后删除这两个目录。本文保存主要结论、关键数值、方法边界与工作路线，不包含原目录中的逐窗数据、图表、脚本、文献检索明细和完整复算材料。

## 1. 核心判断

已有分析支持继续研究**固定电、热任务下，燃机负荷分配、温度控制、汽水压力调度、冷端状态如何共同影响总燃耗和汽机发电贡献**。

当前已有持续的机间表观燃耗差、局部时间变化、冷端与汽机贡献关联，以及MAX压力设定机制的证据。但尚未识别可执行的最优负荷偏置、最优压力或温度设定，也未验证0.1个百分点效率提升。

后续最有价值的新增工作，是核实关键计量与控制定义、建立可比工况和近期参考、识别少数控制方向的整套边际响应。更复杂的模型不能补足缺失的动作激励、维护记录和计量锚点。

## 3. 数据质量、工况与特征工程

### 3.1 `results` 的数据入口与保留原则

预处理全时间轴共613,440分钟、242个测点。新版主要入口原为 `preprocessing/relaxed/efficiency_points.csv`，旧严格筛选结果用于对照。

| 数据层 | 数量 | 分母与含义 |
|---|---:|---|
| 全运行方式核心质量合格 | 525,014分钟 | 占全时间轴85.59% |
| 二拖一效率主分析数据 | 309,575分钟 | 占状态3的325,446分钟95.12% |
| 其中宽松稳定 | 252,305分钟 | 占质量合格二拖一81.50% |
| 后续正常运行研究样本 | 248,913分钟 | 宽松标签基础上，再要求三台机组前后30分钟连续运行 |
| 完整15分钟正常窗口 | 11,040个 | 覆盖165,600分钟，约占正常研究分钟66.5% |

原则是逐点屏蔽确认停更和硬错误，不因无关测点缺失删除整行；不补值，不按效率高低删除数据。正常停机零值、合法恒定热值与未经证实的突跳/固定疑点保留。

宽松稳定只表示短时波动较小，允许缓慢爬坡。启停短平台、停机前负荷转移、缺失后恢复和正常降负荷均可能通过局部波动检查，需结合上下文判断热力状态。

### 3.2 探索目录的聚合与标签

- 五分钟聚合采用时间加权；相邻原始记录间隔不超过60秒才保持前值，不跨长缺口补齐；五分钟覆盖至少80%。
- 半小时聚合通常至少包含5个合格五分钟窗。五分钟数据以窗口起点标时，设备特征与半小时研究表以窗口终点标时，合并前必须统一。
- 共96,192个五分钟窗、16,032个半小时窗。设备特征表有527项，其中482项可计算、45项因不可辨识保留为空。
- 运行标签区分二拖一、一拖一、停机、启停、变工况、稳定性待判等。缺少并网开关、SSS离合器和完整模式位时，标签是发电组合或压力代理，不能等同真实汽水连接模式。
- 热力稳定检查加入蒸汽温压、凝汽器压力等，不只检查功率。最新说明中稳定半小时样本为5,732窗，基础效率候选5,634窗，完整异常事件审计后候选5,631窗；后续具体模型另有输入完整性筛选。
- 原527项特征表尚未整体用最新清洗值重算。涉及坏通道的性能特征需重建；不可辨识项不能填0。

启停回溯、最短持续时间确认和部分离线诊断会使用后续观测。它们可用于历史样本选择，不能直接当作当时已知的在线模型输入。

### 3.3 已定位的关键计量问题

1. **GT2燃气恒值事件：** 2024-09-17 14:57:21.259至09-18 08:44:43.259，64,036条原始记录连续等于33.586517 kNm³/h，历时17.789小时。匹配对照显示记录流量低约22%，功率及其他运行响应没有同量级变化。该段不能作为高效参考；具体故障环节尚未确认。
2. **压力与温度映射：** 某中压排汽压力通道全段约288.59，已排除热力计算；应使用经过一致性检查的冗余通道。部分按名称选取的高压缸排汽温度实际约38—51℃，不符合相应蒸汽状态，必须核对测点位置。
3. **转速与入口压力：** 原转速代理与原生通道存在数rpm偏差；两机入口压力差约8—9 hPa，足以显著改变计算压气机效率排序。替换压力仅是敏感性情景，不能据此认定仪表错误。
4. **单位与计算链：** 热网热量、低压进汽流量、部分喷水流量、IGV、温度设定和燃料温度存在元数据冲突。差压原值、开方/补偿值、选择值、反馈和指令必须分别映射。
5. **热值与时序：** 两路热值替换情景使计算毛效率差中位约0.0981个百分点，但未核定干湿基准、标准状态、取样位置及延迟。不能据此判定哪路正确。热值前后移30—60分钟会改变部分小燃耗差的符号，正确时移尚未确定。

## 4. 效率差、冷端与负荷历史

### 4.1 固定出力—供热区域内存在可解释的状态差异

`results` 固定2 MW出力×20 MW供热网格，只按样本量选Top 5，共24,295分钟，主要来自约420 MW低供热夏秋和约455 MW高供热冬季两个区域。

- 上、下效率四分位组平均差为1.078—1.723个百分点；严格稳态子集重新分组后仍约0.885—1.077个百分点。
- 高效率组汽机多发3.57—8.01 MW，凝汽器压力低0.46—1.25 kPa，两台GT通常同步少发。
- 低供热三格的相对湿度低约18—31个百分点，干球温度没有一致差异。湿空气状态与冷端条件值得联合研究，但缺少冷却设备配置及操作数据，尚未确认冷却系统因果机制。
- 高供热两格即使同处20 MW供热箱，高效率组仍少供热约5—7 MW，存在箱内残余混杂。

高低组由效率选尾，其差值不是操作收益。汽机贡献分解是相同燃料分母下的记账恒等式，不能称为汽机本体效率变化。

### 4.2 近期负荷历史改变了早期机理解释

低供热G1/G3/G5高效率组中，约69.4%/80.9%/78.6%的有效分钟此前15分钟GT平均负荷高于当前3 MW以上。燃料先下降、汽水系统后响应，可形成瞬时较高的发电量/燃料输入比。

在近期负荷较平稳、严格稳态及精确匹配子集中，“高效率伴随更多高压蒸汽”的原始正差不能保持，部分比较转为更少汽流。因此，更多蒸汽和短时高效率不能直接作为持续优化方向。

后续应显式考虑蓄能：`Q燃料 = P + Q供热 + Q损失 + dU/dt`。动态评价用完整过程的累计能量，并检查始末状态，进一步核查采集滤波延迟和压力/流量响应。

### 4.3 变量增量比变量数量更重要

同一批709个时间验证块中，效率模型MAE由出力+供热的0.420个百分点，在加入温湿度、凝汽器压力和负荷分配后降至约0.188；再加此前15分钟GT历史约0.1773。加入全部汽水温压流量反而约0.2152，未见稳定额外改善。

汽水变量对汽机出力却有价值：对应同期解释模型MAE由0.831降至0.244 MW。全范围燃机研究中，增加燃机变量的收益也依赖模型和时期，简单条件模型有时优于更大模型。

启发是采用分层模型：基础任务/环境模型、汽机响应模型、燃机状态模型和控制事件模型逐组比较。上述结果属于已知同期测量的跨日期解释，不能直接称为未来动作预测精度。

## 5. 双机差异、健康变化与㶲分析

### 5.1 表观燃耗差持续存在，最优负荷偏置尚未识别

- `results` 同期近等负荷、近等入口温度9,997个窗口中，GT2计算发电效率平均比GT1低2.411个百分点。
- 探索初步3,684个窗口中，GT1单位发电燃气体积投入相对GT2中位低5.846%。更新后的原生通道与审计筛选仍支持表观不平衡。
- GT1单位出力高压产汽较少、尾部排烟更热，燃机侧优势需结合HRSG和公共汽机评价。
- 探索双机样本约95%的功率差不超过1 MW，独立差动负荷激励不足，不能可靠估计偏离均分策略的收益。

应比较包含ST和辅机响应的边际量，例如：

`边际整套收益_i = (1 + ∂P_ST/∂P_GTi − ∂P_aux/∂P_GTi) / (∂Q_fuel/∂P_GTi)`。

没有这些响应证据时，不按单台平均效率直接决定优先加负荷，也不将公共汽机功率按GT比例分摊后当作真实标签。

### 5.2 性能时间变化存在局部信号，归因仍需事件证据

`results` 119对跨冬季匹配中，后期相对早期：GT1计算效率+0.194个百分点，GT2−0.352个百分点；GT2单位发电气耗+0.510%的区间仍跨零，单位热耗+1.079%同时包含公共热值+0.565%的变化。

连续区段研究中，GT2在2025-07-02至08-22的下降方向较有支持，主模型约每30日−0.078个百分点，较稳定子集约−0.035。精确速率依赖模型和样本，不能换算全年统一劣化率。候选恢复节点均缺少维护记录或充分同工况配对。

探索早期时段的追加反证进一步收紧结论：工况差修正后，压气机湿空气效率损失为GT1−0.0392个百分点、GT2+0.0397个百分点，探索区间均跨零。没有单变量满足该报告整套“持续单向恶化”条件，也没有形成一致的“压气机恶化→整机燃耗上升→余热减少→喷水增加”证据链。

两套结果的时期与指标不同。保留GT2局部性能变化候选，同时保留季节、策略、计量与维护混杂。健康监测使用固定参考，运行寻优使用近期可比参考，两者应分开。

### 5.3 熵与㶲用于机制诊断，不能直接折算可追回收益

`results/gt_exergy` 实际调用燃机模型补充熵产生、化学㶲和完整㶲收支。GT2跨时期模型压气机、透平㶲损分别增约0.625、1.045 MW；总㶲损增2.793 MW，但按燃料㶲归一化仅增0.055个百分点，区间包含零。

压气机比熵差较接近实测温压指标；MW级㶲损依赖空气量反算，透平和燃烧分项进一步依赖入口温度、抽气与冷却等假设。用实测功率反算流量后的闭合属于内部一致性，不能作为独立实验验证。排气㶲进入HRSG利用链路，不属于燃机内部毁灭，不能单独最小化它来优化整套系统。

## 6. 控制、再热与喷水协同

### 6.1 MAX压力调度是值得继续辨识的机制

后续报告在留出数据上较准确地重建“最大汽流→压力设定”：高压MAX输入模型MAE约0.000534 MPa，热再热对应中压设定约0.000022 MPa。这里恢复的是DCS设定关系，尚未验证操作到实际压力和出力的因果响应。

`Fmax = S/2 + |D|/2`，`Pset = f(Fmax)`；S为两炉汽流和、D为差。相同总量下，不平衡改变设定，D=0附近存在折点。模型应按1炉主导、2炉主导、接近均衡分段，而不是跨分支拟合一张统一光滑曲面。

别名 `gt*_ip_flow` 实际为热再热出口流量，包含冷再热、中压新汽和喷水；中压新汽另有通道。必须保留各项物理分解。

### 6.2 冷再热48.2%份额未获独立确认

由热再热减中压新汽及喷水推算的1号冷再热份额中位约48.216%。但温度混合模型存在1/2号约−3.295/−5.808℃闭合偏差，温度反解份额约56.224%，方向相反。区分48.2%与50%的预测温差信号仅约0.2℃，明显小于当前闭合残差。

冷再热调节门主要在近全开区，缺少有效动作变化。份额代理更接近50%也不保证热再热均衡或喷水下降。当前更值得核查中压新汽接入与公共冷再热的替代、积存及补偿计量关系；不能指定最优分流比例。

### 6.3 少喷水尚无稳健节能证据

原实际减温器模型混合温度闭合偏差约13—18℃，应先核对流量、截面和支路。理想局部模型支持减少混合与节流不可逆性，但当前可比喷水差约0.4—1 t/h，对应理想毛效率尺度约0.008—0.012个百分点，不能直接当作电功率或净收益。

同任务局部配对的燃料差在方法间不稳健，多数区间跨零。低喷水应至少分为：

1. 汽温维持且仍有调节开度的低喷水；
2. 喷水近零且汽温下降的受限状态；
3. 近关阀但流量有非零底值的计量待核状态。

例如1号再热近关反馈下941窗的流量中位约1.804 t/h，不能将其全部计作内漏或可节省损失。

### 6.4 最新16段对照说明应保留GT/ST分配路径

16段平均温度设定变化中，高压喷水全部下降，燃料8降8升。增耗8段汽机全部少发，其中7段燃机补发；减耗8段中5段汽机增发、燃机减发，另外3段来自表观耗热比项抵消补发项。

两组喷水降幅相近；燃料差与汽机差的描述相关约−0.691，与高压喷水差仅约+0.156。原16段平均燃料差+1.034 MW、中位−0.200 MW。进一步限制块内供热极差后剩11段，7降4升，但平均差约+0.0035 MW。

这些是小样本历史对照，含环境共同变化、供热分配、动态和计量影响。不能凭下降段数宣布节能。降低温度共模还可能出现高压喷水减少、再热汽温下降、汽机少发的代价；后续应联合评价，不以喷水总量替代燃料目标。

## 7. 历史高效参考与高维结构

多维网格评估固定边界，考察2—8维、2/5/10 MW出力宽度及两组支持要求，共42种配置。5 MW出力网格、至少30个块和10天要求下，整批覆盖由出力+供热二维31.8%，降至加入温度23.4%、湿度7.5%、负荷历史4.6%；五维用早期库支持后期约0.011%。细网格的稀疏不等于物理不可行。

条件邻域、互为近邻图、跨日高效点带与真实联合代表记录已有离线原型结果。19维整机主方案后期1,110个查询中77个有参考，覆盖6.9%；k=12敏感性为14.3%。加入燃机状态扩展33维后主方案约6.8%。不能按同一测试段事后选最有利参数。

整体19维运行数据95%方差约需6个方向；高效点在整体尺度看似2维，按自身尺度仍需6维。高效点范围收窄、样本筛选和季节组成会造成“变薄”，尚未证明唯一最优流形。负荷差等低方差控制方向可能被PCA丢弃，应按物理意义保留。

单机参考覆盖较高，但仅约26%—29%同时满足整机电热任务。两台各自最优点不能拼成整机方案。历史参考年龄常超过180天，差额可能包含基准漂移。

下一步采用粗条件网格+连续邻域+近期参考，返回真实联合状态，并报告源日期、维护周期、支持天数、相似距离、分支、条件差和不足原因。数据保留率、可预测覆盖率、可推荐覆盖率分别统计。

## 8. 凝结水与泵的独立研究支线

- 主泵再循环反馈<1%时，12,514个运行窗口的流量中位约7.393 t/h。可能是算法低端残值、零偏、内漏或截面包含其他支路，尚不能认定为可回收流量。
- 同服务条件稳定匹配中，1号单泵减3号电流中位−1.012 A，165对；2号减3号−1.594 A，88对。3号泵值得复核计量与水力状态。
- 相同需求下单泵与双泵没有合格配对，不能用总体电流差估计少开一台泵收益。
- 缺少有功功率、电压/功率因数、转速及阀态，安培差不能直接换算kW。
- 母管与两炉进水差额随模式变化，边界还缺减温、保护、回流与积存项，不能直接命名为泄漏。

补有功功率和完整流路后，可建立同流量、压差、温度下的泵参考曲面，并以不同日期验证净收益。

## 9. 后续工作路线与通过标准

| 优先级 | 工作 | 交付与通过标准 |
|---|---|---|
| P0 | 数据及计量统一 | 统一信号编码、单位、标准状态、时区、窗口定义、指令/反馈/计算链、质量位和数据版本；重算受影响特征 |
| P1 | 可比工况与状态层 | 稳态、调负荷、启停分别建样本；确认模式位、MAX激活侧、维护及校准事件；报告共同支持和无匹配区域 |
| P2 | 分层联合响应模型 | 基础任务/天气模型为基线，逐组加入历史、燃机、汽水与冷端；联合评价燃料、ST贡献、汽温汽流及约束 |
| P3 | 近期高效参考库 | 同任务、跨日重复、真实联合记录；输出参考年龄、不确定性与支持不足；固定健康基准和运行参考分开 |
| P4 | 少数控制方向辨识 | 优先负荷差、温度共模/差模与MAX分支交互；先查自然事件，再按现场允许边界设计重复交叉对照 |
| P5 | 健康归因与辅机收益 | 用维护事件、同期对照、前趋势及安慰剂日期区分恢复与偏移；补泵塔有功功率后评价净收益 |

统一评价原则：

1. 固定电任务、供热量及品位、运行模式；毛功率与净功率边界分别声明，辅机变化纳入净收益。
2. 优化目标优先为总燃料热输入或累计燃料能量，同时满足汽温、压力、排放、最小通流、爬坡及执行器裕度等已核实约束。
3. 模型输入区分外部条件、当时状态、真实动作和未来响应；避免把含目标的效率、热耗或反算模型量当作独立预测证据。
4. 按连续运行段和日期切分；隔离最大回看及预测窗口；标准化、参考库、参数选择和不确定性校准仅使用相应训练数据。
5. 不确定性按日、周或独立试验块处理；互不重叠窗口也可能相关。多种筛选复用样本，不累计成新增独立证据。
6. 缺乏联合支持时不外推动作；报告反例、无匹配、变号与模型敏感性。统计图的连通性不代表物理可操作性。
7. 采用重复A/B/A或交叉对照时，由现场核定幅度与时长，等待实际热力状态稳定，检查回归基准后的重复性；本文没有形成现场操作指令。
8. 特征越多不自动越好，高R²不表示能分辨小收益。冻结方案后使用未参与发现的新日期或区域验证。

0.1个百分点目标需与相对提高0.1%区分。代表工况约427.6 MW、毛效率51.71%时，提高0.1个百分点约等价于固定燃料下增加0.827 MW，或固定功率下减少1.596 MW燃料热输入。现有喷水局部信号、热值来源差和模型误差表明，应先评价差分计量与试验块噪声，不能由总样本量或拟合优度承诺达到该目标。
