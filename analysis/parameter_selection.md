## 3. 质量平衡：回路可以连通，但仍需要流量锚点

### 3.1 当前图的结构检验

在 9 个汽水系统中排除热网侧流股，将跨系统同名流股合并，建立 `A m = 0`。轴封加热器的水侧和汽侧各自守恒，不允许通过一个总质量方程使两侧互相“补偿”。数值秩由 NumPy SVD 求得，矩阵和行列顺序已保存在证据 JSON。

| 量 | 数值 |
| --- | --- |
| 独立流股质量流量变量 | 135 |
| 质量方程行数 | 104 |
| 质量矩阵秩 | 104 |
| 只有质量方程时的自由度 | 31 |
| 当前可映射、量纲一致的流量字段 | 29 |
| 这些字段使质量约束增加的秩 | 15 |
| 尚余质量自由度 | 16 |

这里是乐观的结构检验：暂把量纲一致的 DCS 流量输出当作可用独立观测，尚未验证计算值是否依赖其他已选流量。因此 16 是该假设下的剩余自由度，不能理解为必须新增 16 个传感器，也不能据此认定真实数据已经可解。有效独立的焓混合方程、明确的运行泵组合、合并泵组的分析边界，都可以减少新增观测需求。

| 未确定的流量类别 | 自由度 | 处理 |
| --- | --- | --- |

### 3.2 补水暴露的物理边界条件

当前工质侧对外质量端口只有补水、轴封加热器汽侧入口和其疏水出口。表面式轴封加热器不让两侧流体混合，其汽侧稳态满足 `m_gland_steam = m_gland_drain`。主汽水回路中又省略了所有漏汽、排污及其他外流，因此严格稳态下，该简化模型要求补水流量为零。

这不是要求把补水数据强制填成零。应保留 `cond.makeup.m_dot` 作为边界检查：若实测补水非零，需核对实际外流损失或汽包/热井库存变化，并在模型中加入对应项。仍有补水而不画任何主回路外流，不能靠调整给水流量制造闭合。真实质量式应为：

`补水 + 其他实际外部输入 − 实际外部损失 = dM/dt`。

轴封加热器汽侧来源仍未明确；若它实际来自汽轮机漏汽或辅汽，应建立相应来源，而不是把该量默认当成任意独立外部输入。

## 5. 能量平衡与可推导量

统一符号：`Q > 0` 为进入所选边界的热量，`W > 0` 为对外做功。稳态、忽略动能位能时：

`R_m = Σm_in − Σm_out`。

`R_H = Σ(mh)_in − Σ(mh)_out + Q − W`。

泵功输入为正的物理量 `W_pump,in` 对应 `System.work = −W_pump,in`。如果只包工质，轴功和电机电功需要明确区分；电动机不在边界内时不能把电损耗也计入工质能量增量。

### 5.1 喷水、混合和节流

减温器无散热/功时：

`m_steam h_before + m_spray h_spray = (m_steam + m_spray) h_after`。

若已知蒸汽量和三股真实状态：

`m_spray = m_steam (h_before − h_after) / (h_after − h_spray)`。

可用于独立推导或校核，前提是状态在正确的减温器前后位置、绝压已确认、没有两相状态歧义，且分母不过小。压力/T 缺失时不能靠这条式子凭空得到流量。高压喷水量还可由主汽量−给水量求得，但对同一数据再用该差值验证高压质量残差，会人为得到零残差。

普通混合器：`h_mix = Σ(m_j h_j) / Σm_j`；再用实测混合压力 `P_mix` 建立 `from_Ph(P_mix, h_mix)`，取得 T/s。温度一般不是简单算术平均。不同压力输入的节流/混合损失，可在合并边界中核算，不能令所有进出口压力相等。

绝热阀：`m_out=m_in`、`h_out=h_in`。需要 P_out 算出口熵；仅知道压降但入口绝压未知仍不足。低压汽包给水阀需保留阀前 P、阀后 P（用户已确认采用汽包压力）及入口焓，阀后温度可作为冗余校核。

### 5.2 低压省煤器再循环与水水换热器

`m_economizer = m_lp_feed + m_heat_recovery + m_lp_recycle`。

`m_economizer = m_to_drum + m_heat_recovery + m_lp_recycle`。

因此省煤器回流与水水换热器回流在汽包总给水关系中抵消；仅量到 LP 总给水和主汽量不能分别得到这两个循环量。两股返回水入口/混合出口状态充分且独立时，理论上可增加焓混合方程求回流。本轮已确认余热回收混合后P/T与返回水测点；混合前状态仍缺，且用户明确将水水换热器流量留空，不启用反算。

水水换热器锅炉水侧的放热：

`Q_recovery,out = m_recovery (h_boiler_water,in − h_boiler_water,out)`。

这不是热网最终用户收热量；分配管网损失和循环水侧不在此次边界。现在原表里出现“烟气热网换热器凝水入口压力”“烟气热网水加热器出水温度”等名称，其中出水温度可能属于网侧；在核对实际端口前，不能为填缺口而将它们绑定到锅炉水回水状态。

### 5.3 湿蒸汽与汽轮机功

低压缸排汽在饱和区，P 与 T 相互依赖，不能决定干度。需要 P+h 或 P+x。缸壁温度、排汽温度选择值也不能代替干度。

对于包含三个缸、但不包含锅炉再热器的汽轮机系统，可由独立 W_st 及所有其他边界状态重建排汽焓：

`m_lp,out h_lp,out = Σ(mh)_steam,in − Σ(mh)_cold_reheat,out − m_heat h_heat + Q_st − W_st`。

该式的进汽包含两路高压、两路热再热和两路低压补汽。冷再热离开汽轮机，是真实出口，不能在系统能量式中遗漏。假设绝热时 Q_st=0，独立功率仍要对应同一边界。之后用 `x=(h−h_f(P))/(h_g(P)−h_f(P))` 检查干度范围。

以这个能量方程反算 h_lp,out 后，整体 ST 能量残差不能再作为独立验证；应另用干度/末级模型、热井/凝汽器边界或不同工况检验。当前没有运行数据，报告未给出干度数值。

### 5.4 供热与凝汽器单侧边界

单个无轴功汽水换热器的工质侧放热为 `Q_out = Σ(mh)_in − Σ(mh)_out`。若边界还包含疏水泵，则 `Q_out = H_in − H_out + W_pump,in`；不能把疏水泵能量增量当作供热损失而忽略。

凝汽器工质侧同样以进汽、补水、再循环及输出凝结水的完整 H 收支算排热。单侧反算的 Q_out 是平衡结果，不能再把同一个 Q_out 当作独立的热量闭合测量。水水换热器与凝汽器的真实热量残差验证，需要额外独立热边界证据；本次排除网侧/冷却水侧后不作此声称。

## 6. 火用分析的可计算范围

参考环境对所有流股统一使用 `(T0,P0)`。工质物理比火用：

T0/P0 可以采用明确声明的固定参考环境，或采用已核实的室外环境。固定火用参考 P0 不自动等于某工况把表压转换为绝压所需要的实际大气压力；不能为填补压力基准缺口而混用两者。

`e_ph = (h−h0) − T0(s−s0)`，`E_flow = m e_ph`。

一般边界火用毁灭：

`E_D = E_in − E_out + E_Q,in − W`。

E_D 是待计算的不可逆性结果，不能无依据令 E_D=0，再用“火用平衡”解缺测流量。质量和充分独立的能量方程可以补充流量约束；火用式本身不会凭空增加一个已知条件。

恒定边界温度时 `E_Q,in = (1−T0/T_b) Q_in`；温度变化时应使用 `∫(1−T0/T_b)dQ`。T_b 必须是热量穿过所选边界时的温度依据，不是任意平均进出口水温，也不是可自动复用的汽包压力对应温度。

| 边界 | 当前范围可计算 | 条件或限制 |
| --- | --- | --- |
| 绝热阀、分流、混合、泵、汽轮机 | 物理火用收支，状态/功和假设充分时的 E_D | 流量、独立状态、泵功或效率、功率边界需满足；不能用能量差本身当作火用毁灭 |
| HRSG 水侧子系统 | 水侧火用增益及吸热 | 缺真实热边界火用或对应气侧时，不独立求受热面真实 E_D |
| 供热汽水换热器仅工质侧 | 工质火用减少、边界放热、工质可供火用的上限型指标 | 工质火用减少 = 向网侧输出的热量火用 + 本边界 E_D，不能把两项合并称为毁灭 |
| 水水换热器仅锅炉水侧 | 锅炉水火用减少、放热 | 与上一条相同；排除网侧后无法自动分离有用热火用和不可逆毁灭 |
| 凝汽器仅工质侧 | 工质火用减少、排热 | 冷端真实热边界火用未知时不能无条件令其为零 |
| 完整 HRSG，气侧+水侧+泵 | 完整边界物理火用收支 | 整体散热火用与对外功需明确；气侧目前仅整体进出口，不能据此逐级分配受热面 E_D |
| GT/整厂 | 在已说明物理/化学范围内的火用指标 | 燃料化学火用必须补充；当前气体物性只给物理火用，烟气化学/混合火用不完整 |

仅选择机组工质侧并不阻止计算供热量和工质火用变化，但限制了“真实换热器火用毁灭”的可识别性。若希望在保持不采集网侧的前提下分离 E_D，需要单独确认工质侧实际热边界温度分布/边界热火用模型，并标注模型假设。否则结果名称固定为“工质火用减少/增益”，不输出伪精确的 E_D。

按代码约定，`Device.exergy_balance()` 只是流股火用净流入；不能直接当泵或汽轮机火用毁灭。`System.exergy_balance()` 加了 heat_exergy 与 work，只有边界量完整时才具备 E_D 的含义。水侧受热面 `heat_exergy=None` 时不得补零使程序出数。

完整 HRSG/整厂中，气水换热属于内部传热。HP/IP/LP 单独水侧得到的吸热不能再作为完整 HRSG 或整厂的外部 Q 累加，否则能量和火用重复计数。[plant.py](../gard/plant.py) 中的整体锅炉结构已表达这一原则，参数预处理仍需遵守。
